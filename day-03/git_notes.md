# Git & Version Control for Cloud Engineers

## Core Concepts
- **Working Directory**: Untracked/modified local files.
- **Staging Area (`git add`)**: Files indexed and ready to be committed.
- **Local Repository (`git commit`)**: Snapshot of changes stored in `.git`.
- **Remote Repository (`git push`)**: Centralized code host (GitHub).

## Key DevOps Workflow Rules
1. Never commit broken code directly to `main`.
2. Use descriptive branch names (`feature/...`, `bugfix/...`, `hotfix/...`).
3. Write clear, imperative commit messages (`feat: ...`, `docs: ...`, `fix: ...`).
